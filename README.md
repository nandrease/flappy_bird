# Flappy birds game with Phaser 3

**Play online:** [https://nandrease.github.io/flappy_bird/](https://nandrease.github.io/flappy_bird/)

## Setup

```bash
  npm install
```

## Run locally

```bash
  npm run dev
```

## Deploy to GitHub Pages

```bash
  npm run deploy
```

This builds the app into the `build` folder and publishes it to the `gh-pages` branch, which is then served at  
`https://nandrease.github.io/flappy_bird/`.
